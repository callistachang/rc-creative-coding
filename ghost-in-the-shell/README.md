# ghost-in-the-shell

A kaomoji pet in your tmux status bar.

## Prompt

Pick one (or a combination) of the following prompts:

- It’s alive!
- Something that glows in the dark
- Something’s watching
- Graveyard of dead code.

## Setup

Add this line to `~/.tmux.conf`, replacing the path with the absolute path to your clone:

```sh
source-file '/absolute/path/to/ghost-in-the-shell/tmux.conf'
```
